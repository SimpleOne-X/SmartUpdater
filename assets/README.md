# assets

项目统一使用的 logo 资源，放在这里，三个项目共用同一份：

| 文件 | 用途 | 要求 |
|---|---|---|
| `X-logo-128.png` | NuGet 包图标（`SimpleOneX.SmartUpdater`） | PNG，128×128，背景透明，最大 1 MB |
| `X-logo.ico` | 程序图标：`SmartUpdater.Packer`、`MinimalApp.WinForms` 的 exe 与窗口 | 多尺寸 ico（16 / 32 / 48 / 64 / 128 / 256） |
| `X-logo.svg`、`X-logo-<尺寸>.png` | 矢量源文件与各尺寸位图，方便以后重新导出 | SVG / PNG |
